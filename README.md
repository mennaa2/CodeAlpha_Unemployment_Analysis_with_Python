# 📊 Unemployment Analysis with Python

## 📌 Project Overview
This project analyzes unemployment rate data to understand trends, patterns, and the impact of COVID-19 on employment.

---

## 🎯 Objectives
- Perform data cleaning and preprocessing
- Analyze unemployment trends over time
- Study the impact of COVID-19 on unemployment rates
- Identify seasonal patterns
- Generate insights for economic decisions

---

## 📂 Dataset
The dataset includes:
- Date
- Region / State
- Estimated Unemployment Rate (%)
- Other economic indicators

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

---

## 🔍 Analysis Performed
- Data Cleaning (handling missing values, formatting dates)
- Time Series Analysis
- COVID-19 Impact Analysis (Before vs During 2020)
- Regional Analysis
- Seasonal (Monthly) Trends

---

## 📈 Key Insights
- Unemployment rates increased significantly during COVID-19
- Some regions consistently show higher unemployment
- Seasonal trends indicate fluctuations across months

---

## 📊 Visualizations
- Line Chart (Unemployment over time)
- Bar Chart (COVID impact)
- Boxplots (Yearly comparison)
- Heatmap (Correlation)
- Monthly trend analysis
